# User Guide - DigiCare Reception Dashboard

This comprehensive guide helps you navigate and use all features of the DigiCare Reception Dashboard efficiently.

## Getting Started

### Logging In

1. Navigate to the login page
2. Enter your username and password
3. Click "Submit" to access the dashboard
4. If you've been automatically logged out, you'll see a message explaining why

### Navigation

- **Desktop**: Use the sidebar navigation to switch between sections
- **Mobile**: Use the bottom navigation bar to access different features
- **All Devices**: The header provides quick access to notifications and user settings

## Core Features

### Queue Management

The Queue Manager is the central feature of the Reception Dashboard:

1. **View Queue**: See all patients waiting for appointments
2. **Reorder Patients**: Drag and drop to change the order of patients
3. **Mark as Next**: Select the next patient to be seen
4. **Mark as Late**: If a patient is late, mark them accordingly
5. **View Details**: Click on a patient to see their full details

### Appointment Management

#### Adding Appointments

1. Navigate to "Add Appointment" 
2. Fill in patient details including:
   - Name
   - Contact information
   - Appointment type
   - Preferred time slot
3. Submit the form to create the appointment

#### Managing Existing Appointments

1. Navigate to "Appointments"
2. View a list of all scheduled appointments
3. Filter by date, doctor, or status
4. Click on an appointment to view details or make changes

### Patient Information

The Patient Information page provides detailed patient data:

1. **Personal Details**: Name, contact info, age, etc.
2. **Medical History**: Past visits and diagnoses
3. **Appointment History**: Previous and upcoming appointments
4. **Reports**: Access to medical reports and test results

### Consultation Page

During consultations, you can:

1. Add clinical notes
2. Record vital signs
3. Create prescriptions
4. Schedule follow-up appointments

## Advanced Features

### Real-time Updates

The system provides real-time updates for:

- New appointments
- Changes in queue status
- Notifications for important events

### Reports and PDFs

To access reports:

1. Navigate to the patient's profile
2. Click on the "Reports" tab
3. Select the report you wish to view
4. The PDF viewer will open with the selected document

## Troubleshooting

### Common Issues

1. **Session Timeout**: You'll be automatically logged out after a period of inactivity. Simply log back in.
2. **Sync Issues**: If real-time updates aren't appearing, try refreshing the page.
3. **Form Submission Errors**: Check that all required fields are completed before submitting forms.

### Getting Help

If you encounter issues not covered in this guide:

1. Check the documentation in the appropriate section
2. Contact support at support@digicare.com
3. Provide detailed information about the issue, including any error messages

## Best Practices

1. **Data Security**: Always log out when leaving your workstation
2. **Queue Management**: Regularly review the queue to ensure efficient patient flow
3. **Complete Information**: Enter comprehensive information when creating appointments
4. **Regular Updates**: Keep patient information up-to-date

## Keyboard Shortcuts

For power users, the following keyboard shortcuts are available:

- **N**: Move to the next patient
- **F**: Search for a patient
- **A**: Open the add appointment form
- **Esc**: Close any open modal or dialog
